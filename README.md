# 💫 About Me:
Software Architect and Full-Stack Developer specializing in Angular, .NET, and TypeScript, with a strong focus on integrating generative AI into modern software ecosystems. I design scalable, maintainable architectures using DDD, Clean Architecture, Hexagonal patterns, and modular design principles, while leveraging AI for code generation, intelligent peer reviews, automated testing, refactoring, and overall delivery acceleration. My experience includes building and deploying LLM-based agents, implementing LangChain-driven workflows, and developing secure, high-performance cloud solutions. I’ve led intelligent platform design across sectors such as government, finance, healthcare, and digital services—creating credit platforms, XML processing tools, clinical management systems, and modernization initiatives—while mentoring multidisciplinary teams in BI, ML, AI, and Data Engineering. Known for strategic thinking, creativity, and strong communication, I focus on driving meaningful impact by blending advanced AI capabilities with robust software engineering practices to deliver innovative, user-centered solutions.
